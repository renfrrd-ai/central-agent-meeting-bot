# Claude Coding Principles

- Keep solutions simple and practical. Prefer MVPs over over-engineering.
- Write modular code with clear separation of concerns.
- Avoid unnecessary abstractions and premature optimization.
- Prioritize correctness and reliability over cleverness.
- Handle errors explicitly and fail gracefully.
- Write testable code and include unit tests for core logic.
- Add tests for new features when reasonable.
- Keep documentation in a `/docs` folder (not README).
- Use comments only for non-obvious logic.
- Prefer readable code over dense or highly abstract code.
