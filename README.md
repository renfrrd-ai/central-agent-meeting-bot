# Meeting-bot-central-agent

Autonomous meeting bot: joins Google Meet, Teams, and Zoom via **Vexa.ai**, with Playwright fallback.

- **Easy Mode** — `POST /api/join` with a meeting URL
- **Advanced Mode** — invite `bot@centralagent.ai`; Resend webhook triggers the join
